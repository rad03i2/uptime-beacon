# Contributing / المساهمة

Contributions are welcome. Keep changes focused, dependency-light, and covered by tests.

1. Fork the repository and create a focused branch.
2. Use Python 3.10+ and install with `python -m pip install -e . pytest`.
3. Run `python -m compileall -q src tests` and `python -m pytest -q`.
4. Update the bilingual README when behavior changes.
5. Never commit credentials, private endpoints, generated environments, or user data.

المساهمات مرحب بها. اجعل التغييرات محددة ومغطاة بالاختبارات، وشغّل اختبارات المشروع قبل إرسال Pull Request، ولا ترفع أسرارًا أو روابط داخلية خاصة أو بيانات مستخدمين.
